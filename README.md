# paper-flow

An Agent Skill for planning, drafting, revising, and auditing scientific prose for logical flow, paragraph coherence, transitions, and IMRAD structure.

This skill was generated from *Creating Logical Flow When Writing Scientific Articles* by Edward Barroga and Glafera Janet Matanguihan using [book-to-skill](https://github.com/virgiliojr94/book-to-skill). The source article was published in the *Journal of Korean Medical Science* (2021), DOI [10.3346/jkms.2021.36.e275](https://doi.org/10.3346/jkms.2021.36.e275), under the [Creative Commons Attribution-NonCommercial 4.0 International license](https://creativecommons.org/licenses/by-nc/4.0/).

The repository contains synthesized guidance and worked reconstructions, not the source article's full text. Reuse must remain non-commercial and retain appropriate attribution to the original authors and source.

## Install

```bash
npx skills add https://github.com/caidao22/paper-flow --skill paper-flow
```

## Contents

- `SKILL.md` — core frameworks, usage guidance, and topic index
- `chapters/` — five study modules covering diagnosis, sentences, paragraphs, transitions, and IMRAD flow
- `glossary.md` — key concepts and definitions
- `patterns.md` — reusable drafting and revision procedures
- `cheatsheet.md` — compact decision rules and flow checks

## Use

Examples:

- "Use `paper-flow` to audit this introduction."
- "Apply `paper-flow` to improve these paragraph transitions."
- "Use `paper-flow` ch05 to check alignment across IMRAD."
